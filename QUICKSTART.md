# The Watterson Family Universe

## 🚀 Quick Start Guide

### Option 1: Open Directly (Easiest)
1. Double-click `index.html` to open in your browser
2. That's it! The website will work right away

### Option 2: Local Server (Recommended)
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if you have http-server installed)
npx http-server

# Then visit: http://localhost:8000
```

### Option 3: VS Code Live Server
1. Install "Live Server" extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"

## 📦 What You Need to Add

The website is fully functional, but you'll want to add your own media files for the best experience:

### Character Images (assets/characters/)
- 8 main GIFs (one for each character)
- 8 action GIFs (special moments)
- **Important**: `anais-smart.gif` should show Anais being a genius!

### Sounds (assets/sounds/)
- 6 UI sounds (click, hover, correct, wrong, success, background music)
- 8 character sounds (quotes/catchphrases)

### Videos (assets/videos/)
- 8 short video clips (5-10 seconds each)

**Don't have media files?** The website will still work - you'll just see placeholder text!

## 🎮 How to Use

1. **Home Page**: Click buttons to explore
2. **Family Page**: Click on character cards to see details
3. **Character Details**: Click "Mood Mode" buttons to change colors
4. **Quiz**: Test your Gumball knowledge with 3 difficulty levels
5. **Easter Egg**: Try the Konami Code! (↑↑↓↓←→←→BA)
