# SOUND FILES NEEDED

Place your sound files in this folder.

## Required Files:

### UI Sounds:
1. `background-music.mp3` - Background music (looping, 2-3 minutes)
2. `click.mp3` - Button click sound effect (short, 0.5s)
3. `hover.mp3` - Hover sound effect (subtle, 0.3s)
4. `correct.mp3` - Correct answer sound (cheerful, 1s)
5. `wrong.mp3` - Wrong answer sound (funny/error, 1s)
6. `success.mp3` - Success/celebration sound (exciting, 2s)

### Character Sounds (click on character to hear):
1. `gumball.mp3` - Gumball quote or catchphrase
2. `darwin.mp3` - Darwin saying something sweet
3. `anais.mp3` - Anais being smart or sassy
4. `nicole.mp3` - Nicole being mom-like or angry
5. `richard.mp3` - Richard saying something funny/confused
6. `jojo.mp3` - Jojo saying something weird
7. `penny.mp3` - Penny being sweet/supportive
8. `carrie.mp3` - Carrie being sarcastic or goth

## Tips:
- Use MP3 format for best compatibility
- Keep UI sounds short (under 2 seconds)
- Compress audio to 128kbps for web
- Character sounds can be 2-5 seconds
- Background music should loop seamlessly
- Volume should be balanced (not too loud)

## Where to find sounds:
- Extract from episodes (with proper credit)
- Create your own sound effects
- Use free sound libraries
- Record voice impressions (for fun!)

## Audio Format Guidelines:
- **Format**: MP3
- **Bitrate**: 128kbps (good quality, small size)
- **Sample Rate**: 44.1kHz
- **Channels**: Stereo (for music) or Mono (for effects)
