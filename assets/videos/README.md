# VIDEO FILES NEEDED

Place your character video clips in this folder.

## Required Files:

### Character Moment Videos (5-10 seconds each):
1. `gumball-moment.mp4` - Iconic Gumball moment
2. `darwin-moment.mp4` - Heartwarming Darwin moment
3. `anais-moment.mp4` - Anais being genius/solving problems
4. `nicole-moment.mp4` - Nicole being awesome or scary
5. `richard-moment.mp4` - Richard being hilarious
6. `jojo-moment.mp4` - Jojo being weird
7. `penny-moment.mp4` - Penny being amazing
8. `carrie-moment.mp4` - Carrie being cool/mysterious

## Tips:
- Keep videos short (5-10 seconds maximum)
- Use MP4 format with H.264 codec
- Resolution: 720p or 1080p
- Frame rate: 24fps or 30fps
- Bitrate: 2-5 Mbps for good quality
- File size: Under 5MB per video

## Video Content Ideas:
- **Gumball**: Chaotic scheme gone wrong, funny reaction
- **Darwin**: Sweet moment with Gumball, emotional scene
- **Anais**: Solving a complex problem, being smarter than everyone
- **Nicole**: Being super mom, showing her strength
- **Richard**: Eating something, being confused, funny moment
- **Jojo**: Saying something bizarre, unpredictable behavior
- **Penny**: Shape-shifting, sweet moment with Gumball
- **Carrie**: Floating, being goth and cool

## How to create videos:
1. **Screen capture** from episodes (for personal use)
2. **Trim clips** using video editing software
3. **Compress** for web using Handbrake or similar
4. **Test** playback in browser before finalizing

## Video Specifications:
- **Format**: MP4
- **Codec**: H.264
- **Audio**: AAC, 128kbps
- **Container**: MP4
- **Resolution**: 1280x720 (720p) or 1920x1080 (1080p)
- **Aspect Ratio**: 16:9

## Optimization Tips:
- Use lower bitrate for faster loading
- Consider using WebM format as alternative
- Test on different devices
- Keep file sizes reasonable for web
